# Video Automation Editor

مشروع لإنشاء فيديوهات تلقائيًا باستخدام Python وGitHub Actions.

## المميزات

- البحث عن فيديوهات من Pexels API
- دمج مقاطع الفيديو
- إضافة نصوص على الفيديو
- إنشاء فيديو نهائي جاهز للنشر

## المتطلبات

- Python 3.10
- حساب على Pexels مع مفتاح API
- حساب GitHub
